## 1) جواب سؤال «BOQ عربي هنعمله إزاي»

**الجوهر:** معمارية المحلل **مبنية أصلاً على التعرف بالمرادفات لا بالمواضع** — تبحث في كل
الأعمدة عن نص الرأس («qty»/«unit price»…) بغض النظر عن ترتيبها، فورقة عربية
(الأعمدة معكوسة بصرياً RTL) تُمسح بنفس الآلية. المطلوب **توسيع القواميس** لا إعادة بناء:

| الموضع | الإنجليزي الحالي | الإضافة العربية |
|---|---|---|
| رقم البند | item no / item / no | رقم البند / بند / م / ملاحظة رقمية «م» |
| الوصف | descr* / particul* | الوصف / وصف الأعمال / البيان / البيانات |
| الكمية | qty / quantit* | الكمية / كميه |
| الوحدة | unit | الوحدة / وحدة القياس / الوحدة القياس |
| سعر الوحدة | unit price / unit rate / rate | سعر الوحدة / السعر الإفرادي / سعر المفرد / السعر |
| الإجمالي | total price / total amount / amount | الإجمالي / الإجمالى / المبلغ الإجمالي / القيمة الإجمالية / المبلغ الكلي / القيمة |
| ورقة تُتخطى | summary/pyt/cert/tender/adjust | ملخص / شهادة / دفع / تسوية / مزايد / تعديل |
| فهرس | ^index$ | ^فهرس$ / ^الغلاف$ / ^مقدمة$ |
| عنوان قسم | DIVISION 3: CONCRETE | قسم ٣: الخرسانة / أعمال الخرسانة / DIVISION/قسم |
| نهاية صفحة | TOTAL CARRIED TO COLLECTION | يحمل إلى الجمع / المجموع المحمّل إلى / يجمع إلى |
| أرقام | 0-9 ASCII | طيّ الأرقام الهندية ٠١٢٣٤٥٦٧٨٩ → ASCII في `norm()` |

- **الوحدات العربية** (`م²`/`م٢`/`م³`/`م.ط`/`عدد`/`جملة`/`مقطوعية`/`ل.س`): تبقى نصاً حرّاً كما وردت — قرار قائم §2.5 من دراسة الاستيراد.
- **لغة مختلطة** (رأس إنجليزي ووصف عربي والعكس): القواميس تُدمج — أول تطابق يفوز، والوصف يبقى كما ورد حرفياً.
- **حارس الانحراف:** كل ملف يُستورد بمطابقة خانات Summary/الملخص (§1.4) — يظهر بالمعاينة قبل التنفيذ، عربياً كان أم إنجليزياً.
- اختبارات محلل جديدة بحافظة تركيبية عربية كاملة (نفس أنماط الملف الحقيقي معكوسة اللغة).

## 2) جواب سؤال «ازاي هنربط مع مراحل العمل»

### 2.1 المبدأ المحفوظ (قرار موثق boq-import-design §2.1)

المراحل تملك دلالة دفعات مستقلة (`payPct/payKind`) — **القسم ليس مرحلة** والخلط يفسد
الدلالة. لذلك الربط **خريطة تصنيفية** (قسم ↔ مرحلة) لا دمج للكيانات.

### 2.2 ثلاثة مستويات ربط (موجود جزئياً — المفقود هو مستوى «الجدول»)

| المستوى | الآلية | الحالة |
|---|---|---|
| **بند عقد ← مرحلة عقد** | `BoqItem.stageId` + منتقي في حوار البند | منفذ — يبقى التعديل اليدوي السيد |
| **قسم جدول ← مرحلة قالب** (الجديد) | خريطة `BoqStageLink(docId, divisionCode, stageTemplateId)` | **هذا التصميم** |
| **عقد ← وثيقة BOQ** (نسخ لحظة الربط) | boq-doc-design §7 — المرحلة ب | مصمم — يُفعّل بعدها |

### 2.3 النموذج الجديد

```
model BoqStageLink {
  id              Int
  companyId       Int
  docId           Int   → BoqDoc (Cascade)
  divisionCode    String          // «03» أو «» لبلا قسم
  stageTemplateId Int   → TypePaymentStage
  @@unique([docId, divisionCode, stageTemplateId])
}
```

- وثيقة BOQ تأخذ حقلين اختياريين جديدين: **`customerId Int? → Customer`**
  (جواب «اربط العميل مع الجدول» — و`clientName` النص الحر يبقى للوثائق غير المرتبطة)،
  و**`typeId Int? → ContractType`** («نوع العقد المتوقع» — يحدد قوالب المراحل المتاحة للربط).
- **لماذا قوالب لا مراحل عقد؟** الوثيقة **سباقة للعقد** — المراحل لحظتها وجوداً هي قوالب
  النوع (شاشة أنواع العقود ومراحل العمل). عند التعاقد تتحول الخريطة إلى مراحل فعلية.

### 2.4 الانتقال الآلي عند التعاقد (المرحلة ب — تتكامل لا تتعارض)

```
عقد جديد بنوع T + عميل P + ربط وثيقة D (جاهزة)
  → نسخ بنود D إلى العقد (قرار «نسخ لا مرجع» قائم)
  → لكل بند منسوخ: خريطة D لقسمه (divisionCode) وقالبها من نوع T
    ⇒ يُملأ stageId من المرحلة المشتقّة من القالب آلياً
  → ما لا تطابق له خريطة يبقى بلا مرحلة (يدوي لاحقاً)
  → لو نوع العقد ≠ نوع الوثيقة: تُعرض الخريطة كتحذير في حوار الربط (لا رفض)
```

النتيجة: «اربط مراحل فقط معها» يتحقق على الجدول نفسه، ثم **ينساب** تلقائياً إلى بنود
كل عقد يتربط بالجدول — بلا إعادة اختيار بنداً بنداً، ومع بقاء اليدوي سيداً.

### 2.5 الواجهة — عمود ثالث «الربط»

في شاشة الجدول (§3): عمود الربط يعرض وثيقةً مختارة:
- بطاقة **العميل المرتبط** (منتقي عملاء + إلغاء ربط) — وشارة العميل في عمود القائمة.
- **شجرة الخريطة**: كل قسم (من الأقسام المشتقة) ← منتقي مرحلة من قوالب `typeId`،
  أو «بلا مرحلة»؛ الشارات تظهر بعدد بنود القسم وإجماليه — فترى فوراً أي مرحلة
  تحمل أي قيمة من الجدول.
- عداد تغطية: «نسبة قيمة الجدول المربوطة بمراحل» — مؤشر جاهزية قبل التعاقد.

## 3) جواب «قسم لوحده زي مرجع وإضافة جديد» — أوافق مع تحفّظ واحد

**الموافقة:** ترويج BOQ من تاب الإعدادات إلى **موديول رئيسي مستقل في الشريط**:

- الموديول: **«جداول الكميات»** — أيقونة `TableProperties`، بلا flag، إذن
  `screen_customers` (جمهور العقود نفسه — إدارة + سكرتير؛ انحراف عن adminOnly
  لأنه صار شاشة عمل لا إعداداً — **قرار معلن**).
- الشاشة بنمط الأعمدة المرجعية المعتمد (نمط شاشة الأنواع/الوظائف/المناطق):
  **عمود الوثائق** (قائمة + حالة + إجمالي + شارة العميل) ← **عمود الأقسام والبنود**
  (شجرة مشتقة من divisionCode + شارة كود القسم وعدد البنود وإجماليه + بنود) ←
  **عمود الربط** (عميل + خريطة المراحل + إحصاءات الاستيراد) — والإجراءات العلوية:
  وثيقة جديدة · استيراد ملف BOQ (معاينة → تنفيذ · عربي/إنجليزي) · تعيين جاهزة.
- الجوال: نفس نمط الأعمدة المرجعية المضغوط (قائمة → تفصيل) 375px بلا تمرير أفقي.

**التحفّظ (قاعدة عدم التكرار — درس المناطق/الوظائف):** تاب الإعدادات
«▦ جدول الكميات BOQ» **يُحذف كلياً** — مصدر واحد لكل مرجع؛ شاشة مستقلة واحدة
بلا مدخل قديم موازٍ.

## 5) خطة التنفيذ — مراحل مستقلة قابلة للتحقق

| المرحلة | النطاق | التحقق |
|---|---|---|
| **ق1** | الموديول المستقل (نقل شاشة التاب + نمط الأعمدة + حذف تاب الإعدادات + قائمة/شجرة/تفاصيل) | حي: إنشاء/استيراد/جاهزة + جوال 375 |
| **ق2** | ربط العميل (`customerId`) + الشارة في القائمة | حي: ربط/إلغاء ربط |
| **ق3** | المحلل العربي (قواميس + طيّ الأرقام + اختبارات حافظة عربية) | رفع ملف عربي تركيبي: معاينة → تنفيذ → مطابقة إجمالي |
| **ق4** | `typeId` + خريطة `BoqStageLink` + عمود الربط + عداد التغطية | حي: خريطة قسم↔مرحلة بالشارات |
| **ق5** | الانتقال الآلي عند التعاقد (تكامل المرحلة ب من boq-doc-design) | عقد من وثيقة مربوطة: stageId يُملأ آلياً |

## 6) حدود v1 (معلنة)

1. الخريطة على مستوى **القسم** حصراً — ربط بند↔قالب فردي ليس في النطاق.
2. الاستيراد يبقى **إلحاقاً** بلا استبدال (قرار قائم §2.5.6) — والنسخة المعدلة بأداة الملحقات.
3. ملفات xls القديمة غير مدعومة (xlsx حصراً — قرار قائم).
4. نوع العقد المتوقع غير إلزامي — بلا نوع لا تظهر مراحل للربط، والبنود تبقى قابلة للنقل بلا مرحلة.
