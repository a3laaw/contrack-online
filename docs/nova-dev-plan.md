## الملحق: ما لا تغيره الخطة (ثوابت المشروع)

1. بوابات الاعتماد + تصميم قبل كود.
2. محرك مالي واحد (`postJournalEntry` + السندات) — لا قيود جانبية أبدًا.
3. أرصدة اشتقاقية + لقطات مجمّدة + بذر مؤجل + معرفات لا نصوص.
4. كل جدول يُستخدم فورًا — لا كيانات شبح (درس G3/G5).
5. اختبارات خضراء + lint صفر + تحقق حي قبل أي دفع — والدفع = إنتاج.
6. تحديث `docs/PROJECT-LOG.md` آخر كل جلسة (البروتوكول الإلزامي).
