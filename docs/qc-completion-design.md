# ر1 — اكتمال مديول «العقود وعروض الأسعار» — ورقة تصميم (معتمدة من خريطة التطوير)

> التاريخ: 2026-11-16 · المرجعية: `docs/development-roadmap.md` §ر1 (اعتماد المالك «اعتمد»).
> التصنيف: **B امتداد** — امتداد qc + نموذجي `Quotation`/`Contract` — **بلا مديول جديد ولا جداول جديدة**
> (حقل ارتباط واحد فقط `boq_items.source_quotation_item_id`).
> قواعد §2 من الخريطة مطبقة: تسجيل لا يلزم (الجداول قائمة)، لا enum، ترقيم ذري، audit، حرس الاختبارات.

## 1) البنود الأربعة المعتمدة — القرارات التنفيذية

### ر1/1 — ترحيل بنود العرض إلى بنود العقد (BOQ) عند التحويل

| القرار | التفصيل |
|---|---|
| السلوك | عند إنشاء عقد من عرض (`quotationId` + `transferQuoteItems=true`) تُنسخ بنود العرض (بترتيبها) إلى `boq_items` للعقد الجديد: الوصف · الوحدة · الكمية · السعر · الإجمالي · الترتيب — **نسخ لا مرجع** (نفس مبدأ BOQ المستقلة؛ العقد الموقَّع ثابت وتعديلاته اللاحقة بأوامر التغيير) |
| تتبع الأصل | حقل جديد اختياري `boq_items.source_quotation_item_id → quotation_items.id (SetNull)` — كل بند مُرحَّل يحمل أصلَه (لتقارير المصدر لاحقًا وحرس الترحيل المزدوج) |
| الموضع | داخل معاملة إنشاء العقد نفسها — فشل الترحيل يُسقط الإنشاء كله (ذريًا كوسم العرض) |
| الافتراضي (س3) | الواجهة: صندوق اختيار «ترحيل بنود العرض إلى بنود العقد» **مفعّل افتراضيًا** في معالج العقد عند القدوم من عرض — الخادم ينفّذ الترحيل عند `transferQuoteItems===true` حصرًا (المستدعون القدماء بلا تأثر) |
| بلا مراحل | البنود المُرحَّلة `stageId=null` بلا ربط مراحل — الربط لاحقًا من شاشة المراحل والدفعات (ملكية القوائم المرجعية) |

### ر1/2 — مصفوفة انتقالات حالة العرض + أثر الحالة «مقبول»

| القرار | التفصيل |
|---|---|
| المصفوفة | `جديد → [مرسل، مقبول، مرفوض]` · `مرسل → [مقبول، مرفوض، منتهي]` · `مقبول → [منتهي]` · `مرفوض → [منتهي]` · `منتهي → []` (نهائي) — ترفض التحويل المزدوج عمليًا: العرض المحوَّل يظل «مقبول» ولا يعود للخلف |
| المنطق | `QUOTE_TRANSITIONS` + `quotationTransitionAllowed` (تستبدل any→any) + `quotationAllowedTargets` للواجهة — في `quotes-core.ts` النقي |
| الخادم | مسار `transition` يتحقق بالمصفوفة قبل التحديث (الرسالة: «انتقال حالة عرض السعر غير مسموح (من … إلى …).») + audit كما هو |
| الواجهة | قائمة الحالة في كل صف تعرض **المسموح فقط** — ومنتهي بلا قائمة (نهائي) |
| أثر الحالة | عند قبول العرض في وحدة qc (وجود `onConvertToContract`): يُفتح معالج العقد معبأً فورًا (السلوك المعتمد «يفتح معالج العقد جاهزًا») — وفي موديول المبيعات (بلا المعالج) toast إرشادي فقط |
| الاختبار | `tests/phase9-quotes.test.ts` يُحدَّث لمطابقة المصفوفة (كان يُقفل any→any بمرآة المكتبي — القرار الجديد قرار مالك فوق المرجع المكتبي، موثق هنا) |

### ر1/3 — ترقيم العروض عبر العدّاد الذري

| القرار | التفصيل |
|---|---|
| الحالي | `POST /api/quotes` يقرأ أعلى `quotationNumber` ويولد QUO-%04d (إعادة محاولة 8×) — والعدّاد QUO المضروب في seed بلا استخدام |
| الجديد | `nextNumberByKey("quotation:number", "QUO", 4, tx)` داخل المعاملة + **مزامنة العدّاد فوق الأرقام القائمة** قبل أول استخدام (نمط `voucher:INV` في فواتير Task 107 — العروض القديمة أرقامها أعلى من العدّاد الصفري) |
| البقاء | دالة `nextQuotationNumber` النقية تبقى للاختبارات والمرجع المكتبي، بلا مستدعٍ إنتاجي |

### ر1/4 — ربط العقد بمجموعة عقود عند التحويل (اختياري)

| القرار | التفصيل |
|---|---|
| الخادم | `POST /api/contracts` يقبل `groupId` اختياريًا: تحقق وجود المجموعة (نطاق الشركة) ومطابقة عميلها للعقد، ثم صف `contract_group_items` داخل المعاملة نفسها |
| الواجهة | في معالج العقد عند القدوم من عرض فقط: منتقي «إضافة العقد إلى مجموعة عقود (اختياري)» يُغذى من `/api/contract-groups?customerId=` |
| التعميم | المسار الخادمي عام لأي إنشاء عقد (لا حصر للتحويل) — الواجهة تحصره في التحويل الآن، وتعميمه لاحقًا قرار واجهة فقط |

## 3) المخاطر والضوابط

- **الترحيل المزدوج**: مستحيل — حرس `QUOTE_TO_CONTRACT_MARKER` القائم يمنع العرض المحوَّل قبل الوصول للترحيل.
- **تكرار بنود BOQ**: الترحيل يحدث مرة واحدة داخل معاملة الإنشاء؛ لا مسار ثانٍ يستدعيه.
- **بيانات قائمة**: الحقل الجديد اختياري `null` افتراضيًا — صفر ترحيل قسري، وكل الشاشات القائمة تعمل كما هي.
- **سقف بنود العرض**: الترحيل نسخ مباشر — عرض ببنود كثيرة يعني صفوف BOQ بالعدد نفسه (بلا حدود صناعية — نفس استيراد BOQ القائم).
- **الإنتاج**: `db push` للسكيمة عبر Pooler قبل/مع النشر، والتحقق الحي بعد النشر.
