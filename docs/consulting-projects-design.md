# تصميم — المشاريع الاستشارية المستقلة (قرار المالك: الخيار «ب»)

> قرار المالك 2026-11-16: «مديول الاستشارات ليس للمقاولات بل نشاط منفصل» — بعد المراجعة
> تبيّن أن قلب الوحدة (الإسناد والمراجعات) مربوط إلزاميًا بعقود المقاولات. القرار المعتمد:
> **الخيار ب** — كيان «مشروع استشاري» مستقل، مع بقاء ربط عقد المقاولات **اختياريًا**
> لأنشطة الإشراف المرتبطة بعقد (التوصية المعتمدة افتراضيًا).

> **تحديث قرار المالك (الجلسة 18 — 2026-11-17):** «الاستشارات نشاط مستقل خالص — بلا أي ربط
> بعقود المقاولات». سؤال المالك: هل الاستشارات تبع المقاولات؟ الإجابة: لا — موديول مستقل،
> وعليه فبقاعده الشرطي («لو مش تبع المقاولات خليه نشاط لوحده») قُطعت كل الروابط:
> - حُذف عمود `contract_id` من الخمسة: `consulting_projects` و`engineer_assignments` و
>   `engineer_timesheets` و`consulting_revisions` و`engineer_appointments` (الرادار).
> - الإسناد والمراجعات: الهدف **مشروع استشاري إلزامي** (تحقق خادمي برسالة عربية صريحة).
> - الساعات: ربط بمشروع استشاري اختياري (الساعات الإدارية بلا ربط) — بلا عقود.
> - الرادار: مواعيد على العملاء — بلا عقود.
> - أُلغيت أحداث `contract_events` المولدة سابقًا للمراجعات المربوطة بعقد.
> - بيانات الإنتاج قبل القطع: صفوف الارتباط بالعقود كلها من بذرة التحقق الآلي (`verify-con`،
>   3 مراجعات على عقد الاختبار 16) — حُذفت مع القطع، ولا بيانات حقيقية أُتلت.

## 1 — التصنيف (بروتوكول القرار)

- **الطلب**: جعل الاستشارات نشاطًا مستقلًا يُباع لعملاء، لا موردًا بشريًا لعقود المقاولات فقط.
- **التصنيف**: **C كيان جديد واحد** + **B امتداد** للجداول القائمة (حقول اختيارية فقط).
- **الجداول المتأثرة**: جديد `consulting_projects` · امتداد `engineer_assignments` /
  `engineer_timesheets` / `consulting_revisions` (حقل `consulting_project_id` اختياري) ·
  جعل `contract_id` **اختياريًا** في الإسنادات والمراجعات.
- **المبرر (شرط C)**: الإلزام الحالي بالعقد يمنع النشاط المستقل — مكتب بلا عقود مقاولات
  لا يستطيع إسناد مهندس لأي شيء. لا امتداد يصلح ذلك دون الكيان.
- **المخاطر**: لا يمس أي نموذج مالي؛ بيانات قائمة سليمة (contractId السابق يبقى قيمته).

## 2 — النموذج `ConsultingProject` (consulting_projects)

| الحقل | النوع | ملاحظات |
|---|---|---|
| projectNumber | String | `CPR-0001` — عدّاد ذري `nextNumberByKey("consulting_project:number","CPR",4)` |
| customerId | Int? | العميل (اختياري — يسمح بمهام داخلية) |
| name | String | اسم المشروع/المهمة الاستشارية — إلزامي |
| serviceType | String | من `SERVICE_TYPES`: تصميم/إشراف/دراسة جدوى/تصميم داخلي/ترخيص/إدارة مشاريع/مساحة/أخرى |
| fee | Decimal(18,3) | الأتعاب المتفق عليها (استرشادي — لا قيود محاسبية) |
| status | String | `CONSULTING_PROJECT_STATUSES`: جديد/قيد التنفيذ/معلق/مكتمل/ملغي |
| startDate/endDate | String | YYYY-MM-DD |
| contractId | Int? | ربط **اختياري** بعقد مقاولات (أنشطة الإشراف على العقد) |
| notes/createdBy | String | |

فصل الشركات: `companyId @default(1)` + تسجيل `TENANT_MODELS` (درس T111) + `BACKUP_MODELS`.

## 3 — الأهداف (Target) في الإسناد/الساعات/المراجعات

| الجدول | قبل | بعد |
|---|---|---|
| engineer_assignments | عقد **إلزامي** | مشروع استشاري **أو** عقد — واحد على الأقل إلزامي، وكلاهما مسموح |
| engineer_timesheets | عقد اختياري | مشروع استشاري اختياري **أو** عقد اختياري (الساعات الإدارية بلا ربط كما هي) |
| consulting_revisions | عقد **إلزامي** | هدف واحد إلزامي: مشروع استشاري **أو** عقد |

- ترقيم الإصدارات `revNo` يصبح لكل **(هدف، عنوان)**: الإصدارات على العقد كما هي حرفيًا،
  والإصدارات على المشروع تُرقَّم داخل المشروع.
- حدث العقد (`contractEvent`) يُكتب حصرًا عند المراجعات المربوطة بعقد.
- حذف مشروع استشاري مرتبط بإسنادات/ساعات/مراجعات **مرفوض** (حماية التتبع).

## 4 — الواجهة والتنقل

- قسم جديد أول الوحدة: **«المشاريع الاستشارية»** (`consulting-projects`) — بطاقات ملخّصة
  (الرقم/الاسم/العميل/الخدمة/الأتعاب/الحالة + عدادات الارتباطات) ونافذة إضافة/تعديل وحذف محمي.
- نافذتا الإسناد والمراجعات: مبدّل هدف «مشروع استشاري | عقد» — والساعات ربط اختياري بالمبدّل نفسه.
- المؤشرات الرأسية: بطاقة «مشاريع قيد التنفيذ».
- لا صلاحيات جديدة (`screen_consulting` نفسه) — لا لمس للنماذج المالية.

## 5 — التسجيلات الإلزامية (قواعد البناء §2)

`TENANT_MODELS` (db.ts) · `BACKUP_MODELS` (backup-dump.ts — بعد engineer وقبل الإسنادات
لترتيب FK) · nav-structure (قسم + تاب علوي) · modules-catalog (وصف محدَّث) · audit لكل تغيير.

## 6 — التوافق

- الإسنادات/المراجعات القائمة على العقود تعمل كما هي (contractId ما زال موجودًا).
- API القديم الذي يرسل `contractId` فقط يظل صالحًا؛ رسالة الخطأ تغيّرت من
  «اختيار العقد إلزامي» إلى «اختيار المشروع الاستشاري أو العقد إلزامي».
